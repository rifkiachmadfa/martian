## Prioritas sumber kebenaran
- Desain/fitur: GDD resmi MARS: LAST HARVEST v1.2.
- Implementasi: file dan konfigurasi repository Unity yang aktual.
- Status/progres: dokumentasi ini, tetapi wajib diverifikasi terhadap repository.
Jika ada konflik, jangan menebak. Jelaskan konflik dan minta keputusan.

## Aturan pemakaian
- Baca hanya file yang relevan dengan tugas; jangan memuat semua dokumen jika tidak perlu.
- Jangan menganggap contoh atau status lama sebagai kondisi terbaru.
- Jangan menciptakan fitur di luar cakupan GDD.
- Jangan mengarang versi Unity, package, nama file, scene, referensi Inspector, atau hasil tes.
- Saat kode berubah, usulkan pembaruan dokumen terkait.
- AI bekerja dengan patch; pengguna yang menerapkan, menguji, commit, dan push.

## Aturan sinkronisasi
Setiap perubahan proyek wajib memperbarui AI_CONTEXT dalam patch yang sama. Rincian ada di `04_CODE_RULES.md` bagian "Sinkronisasi AI_CONTEXT".
