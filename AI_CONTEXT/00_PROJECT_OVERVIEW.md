# Project Overview

- **Judul:** MARS: LAST HARVEST
- **Engine:** Unity 2D (versi aktual harus diperiksa dari `ProjectSettings/ProjectVersion.txt`)
- **Genre:** Survival, farming, exploration, resource management
- **Perspektif/visual:** Top-down, stylized/pixel art, Tilemap
- **Mode/platform:** Single-player; target Windows PC dan WebGL
- **Premis:** Astronaut terisolasi di Mars dan harus bertahan selama 7 hari sampai penyelamatan tiba.
- **Tema:** Pulang dan Melestarikan.

## Core loop
Eksplorasi luar habitat → kumpulkan Ice/perbaiki panel → kelola Food, Water, Oxygen, Energy → tanam/panen Potato → tidur dan lanjut ke hari berikutnya.

## Batas produksi
- Proyek tim pemula; solusi harus mudah dipahami dan dirawat.
- Target perangkat spesifikasi rendah (acuan tim: RAM 8 GB).
- Utamakan MVP, kestabilan, dan integrasi daripada fitur tambahan.
- Detail teknis yang belum diketahui harus diaudit, bukan diasumsikan.
